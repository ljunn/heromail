工作方式

一条清晰的注册收码链路

01选择目标平台

用户只选择 GitHub、OpenAI 等目标平台。

02系统分配邮箱

从符合规则的 Outlook / Hotmail 资源中原子分配。

03提交平台注册

复制邮箱并确认已在目标平台触发验证码。

04自动获得验证码

Graph Worker 匹配邮件并提取验证码，超时自动退款。

业务边界

只交付本次任务需要的信息

邮箱是平台资产。HeroMail 只向用户展示分配地址、订单状态和验证码，凭证与完整邮件始终留在加密存储中。

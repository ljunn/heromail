任务流程 / 02

一条链路，四个确定节点。

从目标平台到验证码结果，每一步都有明确状态。你只看到完成任务所需要的信息，敏感凭证始终留在加密存储中。

01选择目标平台

用户只选择 OpenAI、Grok 等目标平台，不能输入或挑选平台邮箱。

↗
02系统分配邮箱

从符合规则的多渠道资源中原子分配，同一平台不会重复占用。

↗
03开始平台注册

下单后系统立即扣费并持续监听对应平台邮件，不需要用户确认状态。

↗
04自动获得验证码

Graph / IMAP Worker 按平台规则匹配邮件，超时未收到自动退款。

↗
信息边界 / 03

只交付这一次任务需要的信息。

邮箱是平台资产。HeroMail 只向用户展示分配地址、订单状态、验证码和本订单匹配的邮件，密码、OAuth Token、其他平台邮件和内部规则不会出现在用户端。
